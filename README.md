# ZapretReborn

Портативное приложение для управления скриптами Zapret. Приложение распространяется как self-contained single-file EXE и не требует отдельно устанавливать .NET Runtime.

## Установка

1. Скачайте `ZapretReborn.exe` со страницы [Releases](https://github.com/ConDucTorLehich/ZapretReborn/releases).
2. Сохраните EXE в папку, в которой приложение сможет создавать файлы.
3. Запустите его. При первом старте можно согласиться на автоматическую загрузку скриптов.

Скрипты распаковываются в папку рядом с EXE. Если запись туда невозможна, приложение использует папку `ZapretReborn` на рабочем столе. Архив загрузки временно сохраняется в `%TEMP%` и удаляется после обработки.

Приложение предназначено для Windows 10 версии 19041 или новее и запрашивает права администратора.

## Использование

### Главная

Выберите скрипт из списка и включите переключатель службы, чтобы запустить его. Выключите переключатель или закройте приложение, чтобы остановить запущенный процесс.

### Сервис

На странице доступны операции с сервисными списками и настройками фильтрации. После изменения системных параметров может потребоваться перезапуск службы или Windows.

### Настройки

Здесь можно выбрать тему, настроить запуск приложения при входе в Windows и проверить обновления приложения и скриптов. Обновление UI заменяет текущий EXE после закрытия программы, затем запускает новую версию.

## Сборка самостоятельно

Из корня репозитория выполните:

```powershell
dotnet publish .\ZapretReborn\ZapretReborn.csproj `
  -c Release `
  -r win-x64 `
  --self-contained true `
  -p:PublishProfile=.\ZapretReborn\Properties\PublishProfiles\win-x64.pubxml `
  -p:PublishTrimmed=false
```
