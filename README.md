# ZapretReborn

**ZapretReborn** — удобное приложение с графическим интерфейсом для управления скриптами обхода ограничений Discord и YouTube через Zapret.

## 📥 Установка

### Способ 1: Автоматическая установка
1. Скачайте последний релиз из раздела [Releases](#) на этой странице
2. Разархивируйте ZIP-файл в любую папку
3. Запустите `ZapretReborn.exe`

### Способ 2: Ручная установка
1. Клонируйте репозиторий или скачайте исходный код
2. Откройте решение в Visual Studio 2022
3. Соберите проект (Target: x64, Configuration: Release)
4. Запустите `ZapretReborn.exe` из папки `bin\Release\net8.0-windows10.0.19041.0\win-x64`

## 🚀 Быстрый старт

При первом запуске приложение автоматически:
- Проверяет наличие скриптов Zapret
- Предлагает скачать и установить их
- Проверяет доступные обновления

## ⚙️ Настройка

### Автоматическая проверка обновлений
Приложение автоматически проверяет обновления каждые 5 минут и отображает индикатор в настройках.

### Темы
- **Системная** — используется тема Windows
- **Светлая** — светлая тема
- **Темная** — темная тема

Выбранная тема сохраняется между запусками.

### Автозагрузка
Включите опцию "Запускать приложение при старте Windows" в настройках, чтобы приложение запускалось автоматически.

## 🔄 Система обновлений

### Обновление интерфейса (UI)
- Источник: [ConDucTorLehich/ZapretReborn](https://github.com/ConDucTorLehich/ZapretReborn)

## ❓ Часто задаваемые вопросы

### Q: Приложение не запускается
A: Убедитесь, что у вас установлен .NET 8.0 Desktop Runtime. Скачайте его с [официального сайта Microsoft](https://dotnet.microsoft.com/download/dotnet/8.0).

### Q: Обновления не находятся
A: Проверьте подключение к интернету. Убедитесь, что GitHub доступен. Проверка обновлений осуществляется через GitHub API.

### Q: Скрипты не работают
A: Убедитесь, что вы скачали скрипты через приложение или вручную. Проверьте, что папка `zapret-*` существует в директории приложения.

### Q: Приложение крашится при открытии настроек
A: Убедитесь, что все файлы приложения целы. Попробуйте переустановить приложение.
